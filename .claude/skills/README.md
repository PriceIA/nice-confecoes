# .claude/skills

Skills do projeto. Cada skill é uma **pasta** com um `SKILL.md` dentro:

```
.claude/skills/
  taste-skill/SKILL.md
  impeccable/SKILL.md
  ui-ux-pro-max-skill/SKILL.md
```

Se a skill vier com arquivos de apoio (`references/`, exemplos, templates), traga a pasta
inteira — não só o `SKILL.md`.

O Claude Code lê esta pasta automaticamente ao abrir o projeto. No Cowork as skills não
aparecem como comando, mas o `SKILL.md` é lido como arquivo e o método é seguido igual.

Usadas na **Fase G** (`docs/fase-g.md`), etapa G2 — a parte visual.

Este arquivo é a única coisa desta pasta que vai para o Git — o resto (394 arquivos, 12,4 MB)
fica só no disco (ver `.gitignore`).
